# CodexLink Android

个人安卓客户端，连接自己电脑上的 Codex 手机后台。Kotlin / Jetpack Compose，最低 Android 8.0，当前版本 0.9.0。

## 数学公式排版（0.9.0）

AI 实时回复和历史回复支持 LaTeX 数学公式：行内 `\(…\)` / `$…$`，独立公式 `\[…\]` / `$$…$$`。支持分数、根号、上下标、方程组、矩阵和求和，可与 Markdown 混排，适配深色模式和系统字体大小；过宽公式缩放至聊天宽度。代码块、行内代码、链接地址和常见美元价格保持原样。

公式在手机本地排版，不调用在线公式服务，也不增加电脑操作权限。流式未写完的公式先显示文本，闭合后渲染；不支持或错误的公式保留可读源码，不修改保存的消息。资源加载和宏定义命令保留为文本。仅聊天空白提示改为“想聊什么？”。

本次只需沿用原签名覆盖安装 `CodexLink-0.9.0.apk`（versionCode 13），继续使用当前 0.8.0 电脑后台，无需因公式显示重启后台。PC 项目根目录随附安装包同步更新。真机重点检查二次方程、分段函数、拍照解题和重新打开历史。

## 每手机仅聊天（0.8.0）

首次使用需覆盖安装 0.8.0 或更新客户端，并启动支持仅聊天的电脑后台。电脑控制台“设置与手机审批 → 7”选手机，再选“3 仅聊天（允许联网）”；也可在设备管理输入 E。手机显示“仅聊天”，只列本设备独立聊天，可联网、解题和发送题目图片，不选择电脑目录，不提供文件、操作审批、接管或交回电脑入口。后台也会拦截这些操作。

切换前需停止或等待本机任务结束；旧模式排队任务取消。模式变化清理旧聊天视图、图片缓存、草稿和重试记录；离线切换再切回也不能重发旧请求。切回普通模式恢复原项目范围，独立聊天保留在仅聊天模式中。手机不能自行解除限制。数学公式排版从 Android 0.9.0 起支持，安装包同步到 PC 项目根目录。

## 使用

1. 在电脑后台设置账号密码、允许操作的项目目录，启动后台与外网连接。
2. 手机填写自己的电脑后台地址、账号和密码。首次登录后，在电脑控制台核对并批准手机，然后手机再次登录。
3. 查看或新建聊天，发送文字和图片，接收实时进度、处理授权和停止任务。

手机保存加密的连接凭据，不保存登录密码；设备私钥保存在 Android Keystore。更换服务器地址时填写自己的固定域名或电脑内网地址，项目没有内置开发者的服务器账号。

## 构建与源码

使用 Android Studio 打开项目，通过本机 SDK 和 JDK 构建。Gradle wrapper、版本目录和源码应提交；local.properties、构建缓存、APK、IDE 私有设置及签名密钥已由 .gitignore 排除。

安装包可以单独放在 GitHub Releases。覆盖升级应沿用你自己的签名，否则 Android 可能要求卸载原应用，导致本机设备密钥丢失并需要重新批准。

更多本地上传准备说明见 PUBLISHING.md，开发待办见 TODO.md。

## 退出电脑端并接管（0.7.0 试用）

配合电脑后台 0.7.0，先在电脑设备管理选择本机，输入 T 开启接管权限。手机打开原聊天点“接管会话”：空闲时直接接管，电脑占用时先显示“退出电脑端并接管”确认，确认后显示退出与恢复进度。原会话 ID 和历史保留，不分叉、不自动重发消息；取消确认不退出电脑端。

电脑后台已修正“仅关闭窗口，仍留在托盘”的问题：改为校验并激活 Codex 窗口后发送菜单退出快捷键 Ctrl+Q，等待真正退出。本次手机端无需重装，重启更新后的电脑后台即可。电脑需要保持登录且未锁屏；窗口激活失败、按键或权限冲突、退出超时会显示具体原因，不自动强杀。

退出会影响整个桌面 Codex，可能中断其他会话任务或未保存草稿；关闭手机也不取消已经确认的操作。试用版只支持同一用户和图形登录会话的 Windows 商店版 Codex，保护独立手机后台，正常退出不成功即失败，不强杀、不删除锁。若由其他 CLI 占用，可能仍无法接管。确认约一分钟过期，响应丢失时只查询原操作结果。旧后台仍可尝试普通接管，但不能远程退出桌面。

请先在没有重要电脑任务时测试。该版本已做只读进程识别与模拟退出测试，尚待用户实测桌面退出。PC 项目根目录随附安装包同步为 0.7.0；每手机审批和目录范围保留。仅聊天／联网解题选项与数学公式渲染仍暂缓。

## 每台手机的操作审批（0.6.0）

配合电脑后台 0.6.0，在“设置与手机审批 → 7 设置手机操作审批”中选择手机设置手动审批或帮我批准。手机“连接”窗口显示本机新任务的审批方式；任务卡片显示该任务实际采用的方式。

修改设置后，新提交的消息使用新方式；已提交、排队、运行和等待审批的任务保留原设置，使用原消息编号重试也不改变。审批与提问仅由原提交手机处理，同项目的其他手机不能代答。重新登录或重启后台保留设备设置；旧设备升级时继承原全局方式。旧后台显示统一审批设置，不支持按手机配置。

帮我批准是官方自动审查，可能拒绝或需要人工处理，不会代答问题。仅聊天模式与数学公式渲染尚未实现。

## 每台手机的项目范围（0.5.0）

电脑后台 0.5.0 可在“设置与手机审批 → 1 审批 / 撤销手机 / 设置手机项目范围”中，为手机设置一个或多个目录，或所有目录。手机“连接”窗口显示本机范围；新建聊天按指定目录选择，所有目录模式可输入电脑上已存在的完整项目路径。目录限制覆盖聊天列表、搜索分页、历史和任务等接口，由后台校验。

范围变化后手机重新连接并清空旧列表、当前聊天显示与内存图片缓存；已接收或自行保存的内容不会被远程抹除。重新登录同一台手机保留范围。旧后台继续按原全局目录工作，不提供每设备范围；要测试新功能，需要同步更新并重启电脑后台。每手机操作审批从 0.6.0 起支持；仅聊天模式及数学公式渲染尚未实现。

## 搜索聊天（0.4.2）

在聊天列表顶部输入聊天名称或项目路径，支持中文与忽略英文大小写的包含匹配。搜索会逐页检查电脑后台允许访问的聊天，包含尚未手动加载的较早聊天；不搜索聊天正文。搜索完成后可直接打开结果，清空搜索恢复原列表；返回列表或点击刷新会重新搜索，连接失败时显示重试入口。兼容 0.4.0 电脑后台，无需升级后台。

## 回复排版（0.4.1）

AI 的实时回复与历史回复支持 Markdown 标题、加粗、斜体、列表、引用、链接、代码块、删除线和表格。正文可长按选择复制，代码按手机宽度换行；用户消息与工具输出保留原始文本。网页链接可点击打开，电脑本地文件路径仍需在电脑上查看。

本次为安卓端显示修复，可继续连接 0.4.0 电脑后台，无需同步升级后台。使用相同签名的 0.4.1 APK 可覆盖安装。

## 历史图片预览（0.3.1）

手机上传的图片在聊天中显示缩略图，点击查看大图，支持双指缩放、拖动和双击还原；刷新或重新打开聊天后会通过设备签名认证从电脑加载。原图已删除时显示不可用提示。电脑后台也需更新至 0.3.1。

## 普通文件附件（0.4.0）

- 在聊天中点“＋ 文件”，从系统选择器选择文件；每个文件最多 10 MB，每条消息的图片与文件合计最多 8 个。
- QQ / 微信的“其他应用打开”或系统分享中选择掌上 Codex，接收后选择新建或已有聊天。文件先进入草稿，点击发送才上传电脑并交给 Codex。
- 导入文件先存手机应用私有目录，未登录时也会暂存，登录后再选择聊天。正常发送失败时保留文件和消息编号供重试。
- 电脑附件目录由本机配置保存，控制台“设置与手机审批 → 6 修改电脑附件目录”可调整；重启连接后对新上传生效，已有文件保留原位置。
- 文件卡片保留文件名和大小；普通文档由 Codex 在电脑端读取处理，手机端暂不提供文档预览或下载。
- 附件目录包含用户文件，不应上传 GitHub；本机目录配置也由 .gitignore 排除。
